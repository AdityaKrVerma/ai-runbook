and "FizzBuzz" for multiples of both — it tests one loop, one conditional chain, and the
modulo operator. Python slicing takes three slots, `[start:stop:step]`, so `[::-1]` means

class name and declares no return type, which is the one piece I got right unprompted.

you've only ever edited someone else's design. My real gap isn't knowledge, it's that Python
and Java are stored together in my head instead of separately, which only writing fixes.
