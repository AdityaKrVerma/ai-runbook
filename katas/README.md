# Katas

8 minutes each, from an empty file, no lookup. Origination speed is the skill being trained —
not correctness. A broken kata written unaided beats a perfect one you looked up.

Naming: `NNN-short-name.py` where NNN is the day you wrote it.

Rotation (repeat the cycle; repetition is the point):

1. Parse a CSV into a list of dicts
2. Merge two dicts, second wins on conflict
3. Flatten a nested list
4. Group a list of dicts by one key
5. Find duplicates in a list
6. Count word frequency in a string
7. Read a file, return the N longest lines
8. Reverse the words in a sentence, keeping the words intact
9. Given a list of numbers, return only the ones appearing exactly once
10. Convert a flat dot-notation dict to a nested dict
